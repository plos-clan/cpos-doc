# 贡献者们

为 CoolPotOS 项目直接或间接贡献的个人或组织

## 组织

- Plos-Clan - CoolPotOS 隶属于 Plos-Clan 组织
- 梦猫大典 - 部分梦猫大典的开发人员参与了 `CP_Kernel` 的贡献
- xingji-studio - 部分 xingji-studio 的成员参与了 `CP_Kernel` 的贡献
- ViudiraTech - 部分 ViudiraTech 社区成员参与了 `CP_Kernel` 的贡献
- 凤梨团队 - CoolPotOS 文档参与开发
